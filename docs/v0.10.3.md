# v0.10.3 — Universo Vivo Global

A v0.10.3 cria a camada persistente do Universo Vivo.

## Responsabilidades
- World State: estado global da carreira.
- Season State: ciclo da temporada.
- Importer: entrada de dados externos.
- Supabase: persistência global.
- Save local: estado específico da carreira.

## Regras
1. Chaves de API ficam somente no servidor.
2. Dados reais importados recebem IDs externos do provider.
3. Jogadores gerados pelo jogo devem ser identificados como gerados.
4. O universo da carreira evolui independentemente do estado atual da API.
5. Falhas de uma competição não devem abortar toda a importação.
