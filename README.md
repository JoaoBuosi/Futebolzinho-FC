# Futebolzinho FC — v0.10.3

Base do Universo Vivo Global: World State, Season State, importer e integração Supabase.

## Objetivo
Preparar o jogo para clubes, jogadores, competições e temporadas persistentes, sem colocar chaves de APIs no navegador.

## v0.10.3
- Estado global persistente por temporada.
- Ciclo de vida de jogadores.
- Importador desacoplado de API-Football.
- Normalização de clubes, competições e jogadores.
- Schema Supabase para universo global.
- Base para transferências, aposentadorias, jovens e estatísticas por temporada.
